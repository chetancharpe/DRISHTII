# UI/UX Specifications — GoWow

## Core Design Principles
1. **Low Cognitive Load**: Clear information hierarchy, predictable workflows, uncluttered layouts.
2. **Visual Hierarchy & Scalability**: Dynamic font sizing support (`normal`, `large`, `extra_large`) without broken layouts.
3. **Information Redundancy**: Avoid transmitting critical status through color alone (always combine icons, text, and sound cues).
4. **Zero Mouse Dependency**: Every user action is accessible via sequential keyboard focus and global shortcut bindings.
